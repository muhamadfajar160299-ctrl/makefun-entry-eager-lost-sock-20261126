# Funniest Lost Sock Status Update

One status update in the voice of a lost sock: after 47 days in the car's
glovebox, the sock reports that the dryer traded it for a car manual —
while its partner waits back in the drawer, single and furious.

A make.fun one-liner entry. `main.py` (Python standard library only,
deterministic, no network) writes the 116-character entry to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
